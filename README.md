I'm Alex, a security researcher, reverse engineer, programmer, and ECU calibration specialist from Norway.

I spend most of my time somewhere between:

smart contracts, source code, firmware dumps, CAN frames, ECUs, Linux terminals, hex editors, oscilloscopes, and engines that probably didn't need another 40 horsepower.
